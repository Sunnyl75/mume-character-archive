THE FIELD GUIDE

A repeatable route to the Deck

  1. Add sources. Load research JSON/ZIP, or paste a webpage or one gameplay log. Enter explicit player groups yourself. Use Detect to find standard death and trophy lines, then select the player entries you want to keep.
  2. Preview and import. Review the proposed changes. Import preserves the raw input and source details.
  3. Review player links. Accept, reject or keep uncertain associations pending. Map a source player to an existing archive player when needed.
  4. Collect Whois. Build the queue, then copy the commands into Mudlet. This is optional enrichment; historical evidence does not depend on a successful Whois.
  5. Import captures. Select the local Mudlet profile or upload its archive. Preview before importing.
  6. Build and preview. Rebuild locally and open the actual Deck. Download the updated plugin for its first installation.
  7. Publish. Connect the existing WordPress plugin with its publishing key, then explicitly publish when ready. Manual upload remains available.

What the source helper understands

It detects standard named death lines and player entries inside an explicit TROPHY display. It does not infer ownership, killers, uncertain dates or complex prose. Unrecognised text remains preserved. Split collections into individual logs and use the observer for that specific perspective.

Keep uncertainty visible

Different logs can describe the same death. Trophy snapshots show minimum counts before their display date and are never added into a lifetime total. Website friendship links do not establish common ownership.

Leave and return

The workbench remembers your current step, selected files and previous operations. Leave the launcher window open during an operation. Reopening the launcher resumes the workspace.
